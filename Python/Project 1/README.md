
# Student Grade Calculator

In proje yek barname sade baraye sabt etelaat daneshjooyan va mohasebe miangin nomarat anha.

## Features

- Daryaft tedad daneshjooyan
- Sabt Name daneshjoo
- Sabt ID daneshjoo
- Daryaft tedad dars
- Sabt nomarat dars
- Mohasebe miangin nomarat
- Tashkhis vaziyat Ghabooli ya Mardoodi
- Namayesh gozaresh har daneshjoo

## How to Run

1. Python ra nasb konid.
2. Folder proje ra baz konid.
3. Terminal ra dar folder proje baz konid.
4. Command zir ra ejra konid:

```bash
python student.py
```

## How It Works

1. Dar ebtedaye barname tedad daneshjooyan daryaft mishavad.
2. Etelaat har daneshjoo mesle Name va ID sabt mishavad.
3. Tedad doroos daneshjoo daryaft mishavad.
4. Nomarat tamame doroos vared mishavand.
5. Miangin nomarat mohasebe mishavad.
6. Agar miangin 10 ya bishtar bashad, daneshjoo Pass mishavad.
7. Dar gheyr in sorat daneshjoo Failed mishavad.
8. Dar nahayat gozaresh har daneshjoo namayesh dade mishavad.

## Passing Condition

Minimum Average for Passing: 10

- Average >= 10 : Pass
- Average < 10 : Failed
