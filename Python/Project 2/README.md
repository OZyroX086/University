
# Calculator

In proje yek mashin hesab sade ast.

## Features

- Jam (Addition)
- Tafriq (Subtraction)
- Zarb (Multiplication)
- Taghsim (Division)
- Tavan (Power)
- Baghi Mande (Remainder)
- Tarikhche Mohasebat (Calculation History)
- Error Handling
- Menu System
- Wait for Enter before returning to the menu

## How to Run

1. Python ra nasb konid.
2. Folder proje ra baz konid.
3. Terminal ra dar folder proje baz konid.
4. Command zir ra ejra konid:

```bash
python calculator.py
```

## How It Works

1. Barname ba namayesh menu asli shoroo mishavad.
2. Karbar yek gozine entekhab mikonad.
3. Bar asase gozine entekhab shode, amaliat riazi anjam mishavad.
4. Natije namayesh dade mishavad.
5. Natije dar tarikhche zakhire mishavad.
6. Baraye bazgasht be menu, karbar bayad Enter bezanad.
